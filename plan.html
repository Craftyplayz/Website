Navigation files that get added

            

                
FileJob

                
data/site.jsonThe list of every page: title, URL, description, icon, keywords and the date it was added.

                
includes/header.phpBuilds the mega-menu from site.json and highlights the current section.

                
includes/header-fragment.phpThe same header for plain .html pages, fetched by layout.js.

                
includes/subnav.phpA second row of tabs inside a section (replaces shopheader.php).

                
includes/page-nav.php"More in this section" plus prev / next links at the bottom of each page.

                
includes/head.phpTitle, meta description and CSS, so no more "Untitled" pages.

                
assets/js/search.jsThe header search box. Press / to focus it.

                
sitemap/ · sitemap.xml.phpA full page list for people and an XML sitemap for search engines.

                
whats-new/The newest pages, sorted by their "added" date.

                
404.php"Did you mean…?" suggestions.

                
go/ + data/links.jsonShort links (/go/discord, /go/melon) that replace invite.php, spotify.html and shorten.json.
