# Around the Clock (Round the Clock) darts: rules

Also called Round the Clock, Around the World, Round the World, Around the Board. A race: hit every number on the board in order, then the bull. Solo practice and 2 to about 8 players.

## Standard rules

- **Setup.** Standard dartboard, oche at 7 ft 9.25 in (2.37 m) for steel tip. Each player throws one dart at the bull; closest throws first (ties: throw again). Order stays the same all game.
- **Turn.** Three darts, then the next player. Pull the darts and pass the oche.
- **Targets.** 1, 2, 3 ... 20, then the bull. Each player has their own current target, starting on 1.
- **What counts.** Any part of the current number counts: single (inner or outer), double ring or treble ring. Only the current target counts.
- **Advancing.** A hit moves you to the next target, and the next dart in the same turn aims at it. A great turn clears up to three targets.
- **Out of order does not count.** Hitting any other number (even the next one) does nothing. You cannot bank it.
- **Finishing.** The bull is last. In the standard game either bull counts (outer 25 or inner 50). Many boards or clubs are stricter: see variants.
- **Last target on the first dart.** Hit the bull with the first dart of a turn and you finish on that dart. The remaining two darts are not thrown. The "darts used" count stops there.
- **Winning.** First to hit the bull wins. In groups, others may play on for second, third and so on.
- **Bounce-outs.** A dart that bounces out or falls out does not count and is not re-thrown: it is a thrown dart. A dart that sticks in the board but lands in a wire or between segments counts as the segment where its tip sits. A dart that hits the floor or lands off the board is a miss.
- **Darts that land in the board before the turn ends.** Only remove darts after the turn. A dart stuck in the board may deflect later darts; they still count where they land.

## Ties (equal turns)

Sources mostly do not cover ties. Common fair practice (and the tracker default):

1. If a player finishes, everyone who throws later in the same round still takes their turn, so every player has had the same number of turns.
2. If only one player finishes, they win.
3. If several finish in that round, the winner is whoever used the fewest darts (a bull with the first dart beats a bull with the third).
4. If still level, it is a tie. Break it with a shoot-off: closest dart to the bull wins, or extra rounds of three darts.

Alternative house rule: first to finish wins outright (turn off "equal turns"). That favours the player who goes first, so use it only when the order was random.

## Rule sets and house rules

What each one changes compared with the standard rules above.

| Name | What it changes |
|---|---|
| **Standard / Any hit** | Single, double or treble of the target all advance by exactly one number. Bull: outer or inner. |
| **Skip ahead (doubles and trebles)** | A double advances 2 numbers (skips 1), a treble advances 3 (skips 2). Singles still advance 1. Called "Doubles and Triples" in some apps and "increase by segment" in DartCounter. Past the end, the jump stops at the last target: you still have to hit the bull. |
| **Doubles only** (Doubles Around the World, "double round the clock") | Only the double ring of the current number counts: D1, D2 ... D20, then the double bull. Singles and trebles do nothing. Much harder. |
| **Trebles only** | Only the treble ring counts. No treble bull exists, so the bull stays a normal finish (or the inner bull). |
| **Singles only** | Doubles and trebles do not count (some bars use this to make practice harder on the rings). |
| **Finish on single bull (outer, 25)** | Only the green outer bull ends the game. Inner bull is a bullseye that does not count. Easier because the area is bigger. |
| **Finish on bullseye (inner, 50)** | Only the red centre ends the game. Hardest. |
| **Either bull** | Both count. Standard. |
| **Bull first** | Bull is the first target, then 1 to 20. A quick early bull is a head start. |
| **Bull last** | Standard. Gives trailing players a chance to catch up. |
| **Reverse / 20 down / High to Low** | Go 20, 19, ... 1, then the bull. DartCounter also offers bull first. Targets are the same, just a different order and a different feel (you finish on the low numbers near the top-left). |
| **Random order** | The 21 targets (including the bull) are shuffled. DartCounter offers this. |
| **Multiple hits required** | You need 2 or 3 hits on each number before moving on (DartCounter "hits required"). Slower, tests consistency. Skip-ahead is normally dropped with it. |
| **Continue while hitting** | Some groups end your turn at your first miss, so you throw again only after hitting. Not common. The mainstream version always gives three darts. |
| **Slip-up** | You must hit at least one target on each three-dart turn or you "slip up" and cannot go further. A tougher survival twist. Not built into the tracker. |
| **180 Around the Clock** | Three darts per number 1 to 20, 60 darts total. Single hit = 1 point, double = 2, treble = 3 (some sources: singles and doubles 1 point each, treble 3). Score on the number, highest total wins (max 180). A scoring game, not a race. Not built into the tracker. |
| **Equal turns** | Players later in the round still throw after someone finishes (see Ties). |
| **First to finish wins** | No equalising turns. |
| **Value over 20** | One computer game (Bully's) lets a double/treble count as a single if its value would exceed the target. Not a normal dartboard rule. |

### Related games that are not the same

- **Shanghai.** Each round has a number (1 to 7 or 1 to 20). Score the segment values hit on that number. Hit a single, a double and a treble of the round's number in one turn and you win instantly (the Shanghai). A points game, not a race. Not built into the tracker.
- **Fives.** Not a standard Around the Clock variant: a different game where scores divisible by 5 count. No documented Around the Clock rules use it.
- **Killer, Cricket, 501.** Different games.
